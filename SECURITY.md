# Security Policy

## Supported versions

Only the latest commit on the default branch is supported.

## Reporting a vulnerability

This repository ships CSS only, so the practical attack surface is minimal.
If you still believe you found a security issue, use GitHub private
vulnerability reporting (the Security tab of this repository) instead of
opening a public issue.

Anything that is not a security issue (color glitches, layout problems) is
better served by a regular bug report.
