# Solarized Dark — ULauncher Theme

A clean, refined dark theme for [ULauncher](https://ulauncher.io) built on the timeless **Solarized** color palette by Ethan Schoonover.

## Color Palette

| Role               | Hex       | Variable        |
|--------------------|-----------|-----------------|
| Background         | `#002b36` | `$black`        |
| Background Alt     | `#002029` | `$grey-800`     |
| Border / Divider   | `#004152` | `$grey-650`     |
| Body Text          | `#91a0a1` | `$grey-350`     |
| Emphasized Text    | `#ede7d3` | `$white`        |
| Accent (Blue)      | `#268bd3` | `$blue-dark`    |
| Accent (Teal)      | `#29a298` | `$teal-dark`    |
| Muted Text         | `#677879` | `$grey-550`     |

## Installation

```bash
# Clone the theme into the ULauncher user themes directory
git clone https://github.com/cipheraenys/ULauncher-SolarizedDark \
  ~/.config/ulauncher/user-themes/ULauncher-SolarizedDark
```

Then select **Solarized Dark** in ULauncher Preferences > Color Theme.

To update later, run `git pull` inside the cloned folder.

## Requirements

- ULauncher 5.x or 6.x
- GTK 3.20+
